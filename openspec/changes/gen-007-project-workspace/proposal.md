# Proposal

## Why

GEN-001～006 规划了模板、生成、持久化和候选检查，但尚未形成用户能直接完成的工作台路径。`GEN-007` 将这些能力接入真实的创建入口、项目导航、对话、任务活动、预览与只读源码，让面试演示能够从描述需求开始，并在错误或重新打开后继续确认项目状态。

## What Changes

- 以实际模板目录、匿名会话和最近项目组成创建入口，明确点击后创建项目并启动一次生成；页面挂载、示例提示、刷新或重连不能自动调用模型。
- 新增 `/projects/:projectId` 工作台，提供项目切换、需求输入、已保存对话、真实任务活动、取消与结果查询。草稿、请求和版本选择按项目隔离，旧页面响应不能污染新项目。
- 接入 GEN-005 的 POST SSE 与 JSON 重复请求分支，对分块、UTF-8、事件顺序、关联、心跳和体积进行有界处理；断流只查询原请求，不自动重发计费操作。
- 对话首次打开读取最新一页并按需加载更早记录；兼容扩展原消息接口的向后分页，保留现有 afterSequence 模式。确保项目 latestRun 含查询所需的公开请求标识，不新增任务列表服务。
- 复用 GEN-006 的预览、采用与结果确认控制，区分当前版本和未采用候选；未采用候选不能被误当成下一次生成基线，失败保留服务端当前版本。
- 增加所选快照的只读文件列表与源码视图，源码作为文本显示，文件/版本与预览一致；不引入代码编辑、Diff 或历史恢复。
- 处理项目创建结果未知、生成取消待确认、采用结果未知、会话失效及重启后 interrupted；已受理输入与版本从服务端恢复，不补造活动历史。
- 遵循既有设计 skill 提供桌面工作台和手机聊天/预览/代码视图。首页改为真实创建入口，原连接检查迁至独立诊断页并保留原 smoke 回归。
- 增加纯状态/客户端测试及从真实 UI 发起的受控 SDK、SQLite、浏览器集成验收；默认不访问真实模型。GEN-008 再整合跨路径回归，GEN-009/010 验收最终部署与真实模型。
- 本轮只生成规划，实施依赖 GEN-001～006 的实际代码，不把 UI 接通或 fixture 通过当成完整产品已验收。

## Capabilities

### New Capabilities

- `project-workspace`: 将已有项目与生成能力组成可操作的创建、对话、任务观察、候选检查、采用、源码查看和重新打开路径，并保持项目隔离与诚实恢复。

### Modified Capabilities

无。当前没有已有长期规格；本变更新增工作台交互，兼容扩展已规划消息读取及公开运行摘要，不改动先前 change 的历史工件。

## Impact

- 前端：创建页、工作台、路由/导航、项目与消息客户端、生成流客户端、状态控制、只读源码及响应式样式；复用 GEN-006 的共享契约、预览与采用。
- 后端/共享契约：消息读取增加最新/更早页模式，latestRun 公开摘要补齐恢复所需字段；将实际新消费的会话、目录、项目、消息及 SSE schema 提入已有中立契约包，不共享模型或存储实现。
- 依赖：前端新增固定 eventsource-parser 解决真实 SSE 分块解析，复用 React、Node 测试器、已有 tsx 和浏览器工具，不增加路由/状态管理/编辑器框架。
- 回归与说明：调整原 smoke 的诊断页入口，新增工作台浏览器回归，更新 README、Development、Verification、必要的 Monorepo 与设计规则；无 Git 发布、服务器部署或默认真实计费调用。
