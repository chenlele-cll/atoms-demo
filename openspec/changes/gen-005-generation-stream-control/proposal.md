# Proposal

## Why

GEN-004 规划的生成内核尚无公开调用与连接生命周期管理，工作台无法观察活动、取消请求或可靠判断断线后的结果。`GEN-005` 将该内核接入受归属保护的任务事件流，并收口并发、断线、重启与关闭行为，防止重复调用和不确定状态被误报为成功。

## What Changes

- 新增生成 POST、按客户端请求标识查询状态和取消三个接口，复用 GEN-003 的匿名会话、Origin、运行时契约与安全错误；公开请求不能改变模型、工具或资源预算。
- 新生成通过同一次 POST 返回 SSE 任务事件，依次提供受理、真实活动和终态；事件不传代码正文、模型思维链或模拟进度。失败在开流前使用 JSON，开流后通过明确终态或状态查询确认。
- 相同请求不重新生成：运行中返回 JSON 状态，已结束返回已存结果；事件不提供历史重放。连接提前断开时中止未完成生成，关闭浏览器后不承诺后台续跑。
- 实现每项目、每会话及全局的有限准入和调用配额，不排队。取消返回已请求取消或已确认终态，成功保存与取消的竞争沿用 GEN-004 的提交边界。
- 为同一数据库约束单个后端服务进程，启动恢复前取得明确所有权；将遗留 running 标为 interrupted，不重新调用模型。正常关闭先停止准入并终止活动流，再关闭数据库与释放所有权。
- 限制 SSE 帧、缓冲、连接等待和心跳，覆盖慢客户端、流写入失败、数据库终态未确认及超时；无有效证据不能显示任务已保存或编译通过。
- 使用真实 HTTP、SQLite、SDK 受控上游、浏览器及现有代理验证首帧、取消、断线、竞争和重启；默认自动化不调用真实模型，不增加生产假模型开关。
- 本轮只生成规划。依赖 GEN-001～004 的实际模板、模型与存储代码；完整工作台由 GEN-007 接入，候选预览/采用及真实业务验收仍由后续任务完成。

## Capabilities

### New Capabilities

- `generation-execution`: 以有归属的 HTTP 任务事件流执行受限生成，提供幂等查询、取消、准入及生命周期恢复，并保证连接故障和进程退出时结果可辨认。

### Modified Capabilities

无。当前没有已有长期产品规格；本变更在 GEN-004 生成与 GEN-003 项目契约之上增加公开执行边界，不改变候选保存和当前版本的含义。

## Impact

- 后端：生成路由、SSE schema/编码、活动运行管理、资源限制、启动恢复与关闭接入；不把模型、SQL 和流状态全部堆入 route。
- 依赖：复用 Fastify、Zod、cookie、限流及 Node stream；将仓库已固定的 proper-lockfile 声明为后端实际运行依赖以保护数据库服务所有权，不增加队列或外部基础设施。
- 前端边界：验证已有 dev/preview 代理对任务流和断线的行为；本次不增加工作台 UI 或尚无产品调用方的客户端层。
- 验证与说明：新增无真实额度的流式 HTTP/浏览器回归，更新 README、Development、Lifecycle、Verification 和必要依赖记录；本地代理通过不作为服务器最终反代或真实模型通过的证据。
