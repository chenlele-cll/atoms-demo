# Spec Delta

## Purpose

为后续应用生成提供可配置、可限制和可验证的服务端模型调用基础。通过独立的本地探针检查真实文本、结构化文件及工具往返能力，同时将自动化替身测试、未执行项目和实际供应商调用结果清楚区分。

## ADDED Requirements

### Requirement: 模型配置只在调用边界生效

系统 SHALL 仅在服务端读取并校验模型凭据、模型标识和调用限制。模型未配置时，既有服务启动和健康接口必须继续工作；显式调用模型或探针时必须返回明确的缺少配置结果，不发起隐式请求。

#### Scenario: 未配置模型时运行既有服务

- **WHEN** 未提供模型凭据并启动当前后端或请求健康接口
- **THEN** 服务按原有配置工作，不因缺少模型而失败，也不请求模型服务

#### Scenario: 缺少凭据或限制值非法

- **WHEN** 操作者发起模型验证，但凭据、模型标识或调用限制不合法
- **THEN** 在请求发出前结束验证并报告安全的配置错误，不输出秘密值

#### Scenario: 用户明确指定兼容服务

- **WHEN** 用户要求使用批准的 HTTPS 兼容端点，并在后端配置 OPENAI_BASE_URL
- **THEN** 只在服务端已校验的允许名单中选择端点，使用同一 Responses 协议，报告实际 baseURL 和 openai-compatible 来源；不接受任意请求参数上游、不跟随重定向、不推断官方 API 权限

### Requirement: 按选定模型执行有限调用

系统 SHALL 使用明确配置的供应商和模型执行请求，设置输出、请求步骤和总时长上限。探针不得自动重试计费请求，不能在模型无权限、不可用或能力不足时静默切换模型或认证方式。

#### Scenario: 指定模型不可用

- **WHEN** 供应商拒绝访问配置的模型
- **THEN** 记录该模型的验证失败，不切换到其他模型或使用本机订阅登录凭据继续请求

#### Scenario: 响应因限制未完成

- **WHEN** 响应达到输出或步骤上限但未交付完整结果
- **THEN** 报告未完成或验证失败，不将半成品当成有效文件输出或能力通过

### Requirement: 文本和文件输出经过实际检查

系统 SHALL 对模型返回值进行运行时检查。文本探针检查实际非空响应；文件探针检查预期结构、入口、文件路径、内容类型和体积。结果只作为能力样例返回，不执行生成代码或写入项目文件。

#### Scenario: 结构化文件样例有效

- **WHEN** 模型返回符合预期的有限文件集合
- **THEN** 文件探针通过并记录验证摘要，未执行代码且未修改模板或项目

#### Scenario: 文件样例无效

- **WHEN** 模型返回非法结构、空内容、受限路径、超限内容、拒绝或不完整响应
- **THEN** 文件探针失败，不使用预置样例冒充供应商返回结果

### Requirement: 工具往返具有真实执行证据

系统 SHALL 通过一个无文件和网络副作用的样例工具，验证模型发起工具调用、工具被执行，以及工具结果返回模型后产生最终响应的完整往返。普通文本中提到工具名称不构成通过。

#### Scenario: 工具完整往返

- **WHEN** 模型调用指定样例工具，工具返回本轮运行标识，模型在后续响应中确认该结果
- **THEN** 工具探针通过，并记录实际调用次数与往返完成状态

#### Scenario: 缺少调用或确认

- **WHEN** 模型只描述工具、调用未知工具、参数不合法，或未在后续响应中确认执行结果
- **THEN** 工具探针失败，不调用真实项目工具或增加无限修复循环

### Requirement: 超时和取消结束活动请求

系统 SHALL 默认不设置操作累计期限（MODEL_TIMEOUT_MS=0），仅在显式配置正值时启用总期限；将显式超时及外部取消传递到底层活动请求，区分二者的结果，清理后续步骤并忽略结束后到达的响应。取消或超时后不得继续探针的剩余模型请求。

#### Scenario: 请求超过截止时间

- **WHEN** 已显式配置正值总时限且模型请求在该时限内未完成
- **THEN** 活动请求被中止，结果标记超时，后续样例标记未执行

#### Scenario: 操作者中断验证

- **WHEN** 操作者在请求运行时取消或中断进程
- **THEN** 请求和待执行步骤终止，结果标记取消；命令不把晚到响应报告为成功

### Requirement: 错误与用量报告不泄露秘密

系统 SHALL 将认证、额度或限流、服务不可用、网络、输出校验、超时和取消转换为安全的分类结果。报告和日志不得包含凭据、完整请求头、提示词、生成正文或原始供应商错误体；供应商未提供用量时必须标记未知。

#### Scenario: 供应商错误包含敏感信息

- **WHEN** 供应商错误体或异常中包含测试密钥、请求内容或其他敏感数据
- **THEN** 可见输出仅包含允许的错误分类和安全元数据，不透传原始内容

#### Scenario: 用量缺失

- **WHEN** 供应商未返回 token 用量
- **THEN** 报告用量未知，不将其记为零用量或零费用

### Requirement: 真实验证独立且结果诚实

系统 SHALL 提供单独显式执行的本地能力探针，按文本、文件和工具分别报告通过、失败或未执行，并标记结果来源。默认自动化检查不得访问真实供应商或消耗模型额度；缺少凭据、探针未执行或仅替身通过时不能宣称真实接入通过。

#### Scenario: 普通自动化检查

- **WHEN** 在无真实凭据的环境中运行默认测试或工程检查
- **THEN** 使用受控响应完成自动化验证，不请求外部模型服务，测试结果不标记为真实供应商验证

#### Scenario: 显式运行真实探针

- **WHEN** 操作者提供有效配置并明确运行真实能力探针
- **THEN** 使用指定模型发出有限请求，报告各项实际结果、耗时和可用的用量；只有全部必需能力通过时整体通过

#### Scenario: 源码与构建产物运行

- **WHEN** 分别使用源码入口和构建后的后端入口执行相同探针
- **THEN** 两者遵守相同配置、限制与报告规则；失败、取消或未执行返回非成功退出结果
