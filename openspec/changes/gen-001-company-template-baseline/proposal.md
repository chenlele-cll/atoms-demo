# Proposal

## Why

当前应用只有连通检查，缺少可以直接复用并验证的企业官网模板。`GEN-001` 先交付一个来源明确、在隔离预览中可操作的模板基线，为后续真实生成提供经过检查的起点。

## What Changes

- 引入 `leoMirandaa/shadcn-landing-page` 的固定提交 `ae3716dbce5c8a26815222bb743994b5717938f1`，保留 MIT 许可证、来源及适配记录，沿用现成页面和组件。
- 将模板作为独立源文件资产维护，固定运行依赖，预编译其 Tailwind 样式，打包必要资源，提供可重复生成的浏览器预览文件集合。
- 增加企业官网模板基线入口，展示模板来源和真实加载状态；在隔离 iframe 中验证导航、FAQ、主题和手机菜单。保留现有连接检查入口及行为。
- 处理上游占位按钮、订阅反馈和通用存储键，避免展示未实现的服务或把模板标记成 AI 生成成果。
- 在现有 Playwright 工具基础上加入模板专用自动化回归，并覆盖本地开发与构建产物的预览、窄屏、故障反馈及恢复。
- 本次只处理一个企业官网模板。模型接入、项目数据库、Agent、流式生成、候选版本采用、完整工作台、分享和完整 Top 1 验收由后续 `GEN` 子任务分别承担；本次不接入这些能力。

## Capabilities

### New Capabilities

- `template-baseline`: 管理来源固定的企业官网模板文件集合，提供隔离预览、真实状态和基础交互，并建立可重复执行的基线验收。

### Modified Capabilities

无。当前没有已有的长期产品规格。

## Impact

- 模板资产：计划新增 `templates/company-landing/`，保留可阅读的上游组件、样式、资源、来源清单及 MIT 许可证。
- 前端：增加模板资源加载器、专用基线页及最小的 Sandpack 预览封装；通过普通页面链接进入，宿主继续使用 React、TypeScript 和 CSS Modules。
- 构建与依赖：增加模板准备脚本及必要的样式编译开发依赖；前端引入固定版本的 Sandpack。上游组件依赖属于预览文件集合，不安装为宿主 UI 依赖。
- 验证与说明：扩展包命令、忽略规则、模板专用浏览器回归及对应文档；保留 `pnpm smoke` 的现有回归。
- 后端、`/api` 契约、现有 manager 和基础设施不在本次修改范围。模板为公开静态资产，后续项目接口可复用其来源清单和文件集合。
